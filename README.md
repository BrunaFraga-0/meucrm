# MeuCRM

Sistema full stack para cadastro e gerenciamento de clientes, desenvolvido como parte de um case técnico para a posição de Desenvolvedor Full Stack Júnior.

## Status do projeto

🚧 Projeto em fase inicial de planejamento e desenvolvimento.

## Objetivo

Construir uma aplicação web que permita autenticar um usuário e realizar o cadastro, a consulta, a edição e a exclusão de clientes.

## Tecnologias previstas

### Backend

* Node.js
* TypeScript
* NestJS
* PostgreSQL
* TypeORM
* JWT
* BullMQ
* Redis

### Frontend

* Next.js
* React
* TypeScript
* CSS

### Infraestrutura

* Docker
* Docker Compose

## Funcionalidades previstas

* Login de usuário
* Autenticação com JWT
* Proteção de rotas
* Cadastro de clientes
* Listagem e busca de clientes
* Edição de clientes
* Exclusão de clientes
* Fila de boas-vindas com BullMQ e Redis
